# חוברת חגי תשרי — מוקאפ אינטראקטיבי

קובץ אחד, ללא תלויות: `index.html`.
לצפייה מקומית — לפתוח את הקובץ בדפדפן.

## מה יש כאן
מוקאפ חוברת עברית (RTL) עם דפדוף אמיתי, גרירה, מקלדת, זום, מסך מלא,
צליל דפדוף עם כפתור כיבוי, ואזורים לחיצים מעל כל הברקודים.

## החלפת עמודים
בראש תגית ה-`<script>` יש מערך `PAGES` (16 עמודים, כרגע מוטמעים כ-base64)
ולידו `LINKS` — מערך מקביל עם אזורי הברקודים והכתובות שלהם.
